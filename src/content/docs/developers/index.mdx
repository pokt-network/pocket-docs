Pocket Network is an open network for data services. As a developer you can use it from either side: publish a service and get paid for every request it serves, or call the services already on the network from your app or agent.

## Blockchain RPC

The Foundation's public RPC at [api.pocket.network](https://api.pocket.network) gives free access to dozens of blockchain networks with no account and no API key. Every network is at `https://{chain-slug}.api.pocket.network`; drop the URL into your existing code:

```bash
# Ethereum mainnet
curl -X POST https://eth.api.pocket.network \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

```javascript
// ethers.js — just change the URL
import { JsonRpcProvider } from "ethers";
const provider = new JsonRpcProvider("https://eth.api.pocket.network");
const blockNumber = await provider.getBlockNumber();
```

```python
# web3.py — same idea
from web3 import Web3
w3 = Web3(Web3.HTTPProvider("https://eth.api.pocket.network"))
print(w3.eth.block_number)
```

Every network and its slug is on [Supported Chains](/developers/supported-chains).

<Callout type="tip">
  Pocket's RPC is standard JSON-RPC. Your existing ethers.js, web3.py, viem, wagmi, or curl integrations work without modification — just change the URL.
</Callout>

## Building Something Heavier?

If you need more than a public endpoint — your own gateway, custom routing, dedicated access, or high-volume production traffic — [PATH](/path/) is the open-source gateway framework for Pocket Network. It handles sessions, supplier selection, quality scoring, and relay signing for any service on the network, blockchain or not. See [Building with PATH](/developers/building-with-path).
